# Content Strategy

> **Purpose:** Build a public presence that generates awareness, builds trust, and feeds the three revenue pillars (coaching / ontology / AI).

---

## Weekly Posting Schedule

| Day | Platform | Format | Series / Type |
|-----|----------|--------|---------------|

| **Tuesday** | LinkedIn | Post 2 of 4 | Drafted by `/linkedin-engine` — edit and post |

## Platform Map

| Platform | Goal | Funnel Step |
|----------|------|-------------|
| IG / TikTok | Mass awareness | £5 lead magnet |
| YouTube | Authority layer | Skool / coaching |
| Skool | Paid community + mini-series | Retention / upsell |
| LinkedIn | Consulting clients, founders | Direct coaching CTA |
| Substack | Relationship depth, list building | Coaching / Skool feeder |

---

## Top-of-Funnel SOP

**LinkedIn (Sunday — 5 min)**
- Run `/linkedin-engine` after `/weekly-review`
- Review 8 ideas, pick 4, confirm drafts
- Schedule Mon–Thu: one post per day, edit before posting

**IG / TikTok / YouTube (weekly)**
- Check schedule above for what's due
- Film, edit, caption + CTA
- YouTube: thumbnail, description with Skool link

**Substack (bi-weekly Wednesday)**
- Write long, edit short — plain subject line
- Cross-post link to LinkedIn + IG story

**Log (2 min)**
- Mark done in weekly plan
- Note what felt on / off for next week's calibration

---

## Funnel Logic

```
IG/TikTok (volume) → £5 lead magnet → email list / DMs → Skool ($55/mo)
YouTube (authority) → long-form trust → Skool mini-series → 1:1 coaching
LinkedIn (precision) → founder recognition → direct booking → value-based coaching
Substack (depth) → list building → pre-qualified readers → coaching / Skool
```
